Official Integration Guide · SDK v0.2.0-beta.2

Embed production-grade school bus tracking in Flutter.

iCue SDK provides an end-to-end live tracking experience with Google Maps UI, smooth route animation, real-time ETA calculations, isolated session lifecycle, and flexible push notifications behind a clean public API.

Flutter 3.10+ Framework constraint
Dart 3.0+ Language baseline
Android 24+ Min Android SDK
iOS 12+ Min Deployment Target
💡
Integration Contract: Initialize the SDK once (or on-demand during login), provide the navigator key or observer to your MaterialApp, and launch tracking with the student's unique identificationNo.

Core Capabilities

🎬

Smooth 60fps Animation

Frame-independent vehicle motion interpolation and real-time bearing orientation on Google Maps.

🛣️

Intelligent Route Rendering

Automatic polyline rendering, path-snapping to roads, and visual markers for stops and student points.

⏱️

Dynamic Real-Time ETA

Continuous arrival time calculation for pickup and drop-off based on live bus telemetry.

🔥

Host-Friendly Firebase

Reuses your app's existing default Firebase app or initializes on-demand without duplicate app conflicts.

🔄

Isolated Session Handling

Storage is namespaced per client. Student switches and tenant updates are handled safely without collisions.

🔔

Decoupled Push Notifications

Opt-in contracts for disabled, host-managed, or SDK-managed FCM push with automatic live tracking deep-links.

Choose an Ownership Model

The iCue SDK offers three distinct notification integration patterns to fit your application's architecture:

Tracking Only (Default)

IcueNotifications.disabled(): Pure bus tracking. Zero Firebase listeners, zero permission prompts, zero push token registrations.

Host-Managed Notifications

IcueNotifications.hostManaged(...): Host passes push tokens to IcueSdk.notifications.setToken and forwards incoming payloads or handles custom routing.

SDK-Managed Firebase

IcueNotifications.firebaseManaged(...): SDK directly listens to FCM streams, registers tokens with the backend, and displays in-app banner overlays.

Multi-Student Push Support

Register notifications for multiple children simultaneously using IcueSdk.notifications.registerStudent(id) with isolated backend routing.

Getting Started

Installation

Install version 0.2.0-beta.2 from the private iCue Cloudsmith repository. The package requires Dart 3, Flutter 3.10+, and access to your organization's package feed.

🔒
Authentication Required
This is a private repository. Store your package token via Dart's secure credential manager; never commit credentials to pubspec.yaml, source control, or public CI logs.
API Token

Method 1: Using the Dart CLI (Recommended)

Step 1 — Store your repository API token

Run this command once and paste your issued token at Dart's secure prompt to save it to your local machine:

Terminal (bash) 
dart pub token add https://dart.cloudsmith.io/icue/icue-sdk/
⚙️
CI/CD Pipelines: Store your token in your CI secrets manager and run:
dart pub token add https://dart.cloudsmith.io/icue/icue-sdk/ --env-var ICUE_CLOUDSMITH_TOKEN

Step 2 — Add the package dependency

Add the package from the hosted endpoint in a single command:

Terminal (bash) 
dart pub add icue_sdk --hosted-url https://dart.cloudsmith.io/icue/icue-sdk/

Platform Setup

Android Configuration

Configure permissions, Google Maps API keys, and minimum SDK version in your host Android application.

1

Add Android Manifest Permissions

Open android/app/src/main/AndroidManifest.xml and ensure the following permissions are present inside the root <manifest> tag:

AndroidManifest.xml 
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.POST_NOTIFICATIONS" />
2

Add Google Maps API Key

Inside the <application> tag of AndroidManifest.xml, insert your Google Maps API key:

AndroidManifest.xml 
<meta-data
    android:name="com.google.android.geo.API_KEY"
    android:value="YOUR_GOOGLE_MAPS_API_KEY" />
🔐
Key Security: Restrict this API key in the Google Cloud Console to your Android package name and SHA-1 signing certificate fingerprint.
3

Set Minimum SDK Version

In android/app/build.gradle (or build.gradle.kts), verify that minSdkVersion is at least 24:

android/app/build.gradle 
defaultConfig {
    minSdkVersion 24  // Required minimum for iCue SDK
}

Platform Setup

iOS Configuration

Configure Google Maps in your iOS Runner target. The SDK queries telemetry directly from the iCue API, so host GPS permissions are not required.

1

Initialize Google Maps in AppDelegate

In ios/Runner/AppDelegate.swift, import GoogleMaps and provide your API key before the application finishes launching:

AppDelegate.swift 
import UIKit
import Flutter
import GoogleMaps

@UIApplicationMain
@objc class AppDelegate: FlutterAppDelegate {
  override func application(
    _ application: UIApplication,
    didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?
  ) -> Bool {
    GMSServices.provideAPIKey("YOUR_GOOGLE_MAPS_API_KEY")
    return super.application(application, didFinishLaunchingWithOptions: launchOptions)
  }
}
🔐
Key Restriction: Restrict your iOS Maps API key in Google Cloud Console to your iOS bundle identifier.

Integration

Initialization

The iCue SDK can be initialized at application startup or on-demand whenever the user authenticates or navigates into the tracking feature.

1

Initialize the SDK

Call IcueSdk.init and await completion. Initialization is transactional and will automatically rollback on any configuration error:

lib/main.dart 
import 'package:icue_sdk/icue_sdk.dart';

// Initialize on app startup or dynamically when student signs in
await IcueSdk.init(
  const IcueSdkConfig(
    apiKey: 'YOUR_API_KEY',
    apiUser: 'YOUR_API_USER',
    env: IcueEnvironment.prod, // Use IcueEnvironment.dev for testing
  ),
);
2

Register Navigator Key & Observer

The SDK handles cold-start notification navigation automatically. Attach IcueSdk.navigatorKey and IcueNavigatorObserver to your MaterialApp:

lib/main.dart 
MaterialApp(
  navigatorKey: IcueSdk.navigatorKey,
  navigatorObservers: [IcueNavigatorObserver()],
  // ... your existing app routes and configuration
);
💡
Custom Navigator Key: If your app already owns a GlobalKey<NavigatorState>, register it with IcueSdk.setNavigatorKey(myKey) and pass that same key to MaterialApp.
3

Dynamic Reconfiguration

To switch environments, update credentials, or change schools at runtime, call IcueSdk.reconfigure(newConfig) or call IcueSdk.init with the updated settings. Cached sessions are preserved safely unless tenant credentials change.

Integration

Live Tracking

Open the real-time school bus live tracking screen for any student with a single method call. The SDK handles map rendering, 60fps marker interpolation, and ETA updates internally.

Launching Tracking from a BuildContext

Pass a student identification number to IcueSdk.openLiveTracking from any mounted widget context. The method returns a typed IcueLaunchResult:

lib/screens/student_detail_page.dart 
final result = await IcueSdk.openLiveTracking(
  context,
  identificationNo: '12345', // Student identification number
);

if (result.isFailure) {
  ScaffoldMessenger.of(context).showSnackBar(
    SnackBar(content: Text(result.errorMessage ?? 'Unable to open live tracking')),
  );
}

Launching Tracking Without a Context

When responding to push notifications, deep links, or background tasks where a BuildContext is not readily available, use openLiveTrackingFromRoot:

lib/services/deep_link_service.dart 
final result = await IcueSdk.openLiveTrackingFromRoot(
  identificationNo: '12345',
);
// If the root navigator is not yet mounted, the launch is buffered and replayed automatically.

Student Switching & Session Cleanup

When a user logs out or switches profiles in your app, call IcueSdk.logout() to clear cached student data and detach backend push associations:

lib/services/auth_service.dart 
await IcueSdk.logout();
🛡️
Token Safety: IcueSdk.logout() notifies the iCue backend (/v1.0/logout) to remove student push subscriptions, but it never deletes the underlying device FCM token. This ensures your host application push features continue working uninterrupted.

Integration

Push Notifications

Configure Firebase Cloud Messaging so iCue can alert parents when the bus approaches and open live tracking directly when the notification is tapped.

🔔
Default Firebase App Reuse: The SDK operates on the default Firebase app. If your host application already configures Firebase, the SDK reuses it automatically without any extra initialization steps.

Select Your Notification Contract

Choose the notification contract that aligns with your app's push notification architecture:

lib/main.dart 
// MODE A: Tracking Only (Disabled push listeners)
await IcueSdk.init(
  const IcueSdkConfig(
    apiKey: 'YOUR_API_KEY',
    apiUser: 'YOUR_API_USER',
    notifications: IcueNotifications.disabled(),
  ),
);

// MODE B: Host-Managed (Host provides FCM token & handles routing)
await IcueSdk.init(
  IcueSdkConfig(
    apiKey: 'YOUR_API_KEY',
    apiUser: 'YOUR_API_USER',
    notifications: IcueNotifications.hostManaged(
      token: hostDeviceToken,
      presentation: IcueNotificationPresentation.sdkBanner,
      onNavigationIntent: (intent) {
        // Custom router integration
      },
    ),
  ),
);

// MODE C: SDK-Managed Firebase (SDK manages FCM listeners & tokens)
await IcueSdk.init(
  IcueSdkConfig(
    apiKey: 'YOUR_API_KEY',
    apiUser: 'YOUR_API_USER',
    notifications: IcueNotifications.firebaseManaged(
      autoRequestPermission: false, // Control permission timing manually
      presentation: IcueNotificationPresentation.sdkBanner,
      firebaseOptions: IcueFirebaseOptions.fromCredentials(
        android: const IcuePlatformCredentials(
          apiKey: 'AIza...',
          appId: '1:123456789:android:...',
          messagingSenderId: '123456789',
          projectId: 'your-firebase-project',
        ),
        ios: const IcuePlatformCredentials(
          apiKey: 'AIza...',
          appId: '1:123456789:ios:...',
          messagingSenderId: '123456789',
          projectId: 'your-firebase-project',
          iosBundleId: 'com.example.yourapp',
        ),
      ),
    ),
  ),
);

Multi-Student Family Support

For apps managing multiple children simultaneously, register all student IDs so each child's bus notifications reach the device:

lib/services/family_notification_service.dart 
// Register multiple children for push alerts
await IcueSdk.notifications.registerStudents(
  ['STUDENT_ID_1', 'STUDENT_ID_2'],
  token: devicePushToken,
);

// Query registered children
final registered = await IcueSdk.notifications.getRegisteredStudents();

// Unregister a single student
await IcueSdk.notifications.unregisterStudent('STUDENT_ID_1');

// Unregister all students on account sign-out
await IcueSdk.notifications.unregisterAllStudents();

// Or perform full SDK sign-out (unregisters push tokens & clears session)
await IcueSdk.logout();

Push Notification Lifecycle & Sign-Out (Logout)

When a user signs out or switches accounts in your host application, invoke IcueSdk.logout() to unregister push notification subscriptions on the iCue backend:

lib/services/auth_service.dart 
// Option 1: Full SDK sign-out (unregisters push associations from iCue & clears session cache)
await IcueSdk.logout();

// Option 2: Push unregistration only (keeps SDK session cache intact)
await IcueSdk.notifications.unregisterToken();
🛡️
FCM Token Safety: Calling IcueSdk.logout() or IcueSdk.notifications.unregisterToken() tells the iCue backend (/v1.0/logout) to stop dispatching alerts to this device, but never deletes or invalidates the underlying FCM/APNs token on Firebase. All non-iCue push notifications in your host application remain fully active.

Configuration & API Reference

The complete public API surface exported by package:icue_sdk/icue_sdk.dart.

IcueSdkConfig Properties

Property Type & Default Description
apiKey Required String The organization integration API key.
apiUser Required String Integration client identifier used for backend authentication and storage namespacing.
identificationNo String? (Optional) Initial student identification number to pre-load.
env IcueEnvironment.prod Selects backend environment (IcueEnvironment.prod or IcueEnvironment.dev).
restoreSession false Automatically restore the last active student session on app cold-start.
notifications IcueNotifications.disabled() Sealed notification contract (disabled, hostManaged, or firebaseManaged).

Core SDK Lifecycle Methods (IcueSdk)

Future<void> IcueSdk.init(IcueSdkConfig)

Transactional Initialization

Initializes environment, dependencies, session persistence, and notification handlers with automatic rollback on error.

Future<void> IcueSdk.reconfigure(IcueSdkConfig)

Dynamic Reconfiguration

Updates credentials, environment, or notification settings at runtime without clearing active student sessions.

bool IcueSdk.isInitialized

Initialization Status

Synchronously returns whether the SDK is actively configured and ready to handle tracking requests.

Future<IcueLaunchResult> IcueSdk.openLiveTracking(...)

Open Live Tracking Screen

Pushes the live tracking interface onto the navigation stack for the specified student identification number.

Future<IcueLaunchResult> IcueSdk.openLiveTrackingFromRoot(...)

Root Navigator Launch

Launches tracking via the root navigator without requiring a BuildContext, buffering if not yet mounted.

Future<IcueSetupReport> IcueSdk.checkSetup(...)

Preflight Diagnostic Report

Runs self-diagnostics verifying API credentials, session storage, navigator bindings, and push notification readiness.

Future<void> IcueSdk.logout()

Session Logout

Clears cached student session data and detaches backend push associations while keeping host FCM tokens intact.

Future<void> IcueSdk.setIdentificationNo(String)

Set Active Student

Manually sets the active student identification number and synchronizes push tokens with the backend.

Notification Manager (IcueSdk.notifications)

Future<void> setToken(String token)

Set Device Push Token

Stores the push token and synchronizes it with the iCue backend for the active student.

Future<bool> registerStudent(String studentId)

Register Student Push

Authenticates and registers push notifications on the backend for a specific student ID.

Future<bool> registerStudents(List<String>)

Batch Multi-Student Register

Registers multiple student IDs sequentially for multi-child family applications.

Future<List<String>> getRegisteredStudents()

Query Registered Students

Returns the list of student IDs currently registered for push notifications on this device.

Future<void> handleMessage(dynamic payload)

Unified Message Forwarding

Forwards an incoming notification (accepts RemoteMessage, IcueNotification, or Map) into presentation streams.

Future<void> handleTap(dynamic payload)

Notification Tap Handler

Dispatches navigation intents and opens live tracking automatically when the user taps a notification.

Navigation & Broadcast Streams

Stream<IcueNotification> onNotificationReceived

Foreground Notification Stream

Permanent broadcast stream of notifications received while the host app is running in foreground.

Stream<IcueNavigationIntent> onNavigationIntent

Navigation Intent Stream

Broadcast stream emitted when notification taps require screen navigation, ideal for custom router apps.

Stream<IcueNotification> onNotificationTapped

User Tap Interaction Stream

Emitted whenever the user interacts with an in-app banner or system push notification.

IcueNavigatorObserver

Cold-Start Observer

Install in MaterialApp.navigatorObservers to buffer and replay notification navigation when app launches.

Permissions & Token Management

Future<IcuePermissionStatus> requestPermission()

Request OS Permissions

Prompts the host operating system for push notification permissions and returns the resulting authorization status.

Future<IcuePermissionStatus> permissionStatus

Query Permission Status

Queries current status (authorized, provisional, denied, notDetermined, unsupported).

Future<bool> isPermissionGranted

Boolean Permission Check

Returns true if notifications are authorized or provisional.

Future<void> invalidateProviderToken()

Invalidate FCM Provider Token

Explicitly deletes the underlying device token from Firebase servers and clears local storage.

Payload Utilities & Message Helpers

bool IcueSdk.isIcueNotification(dynamic)

Detect iCue Messages

Checks if an incoming RemoteMessage, IcueNotification, or payload map belongs to iCue.

bool IcueSdk.isIcuePayload(Map?)

Payload Structure Validation

Validates whether a raw data map contains iCue provider keys (AdmissionNo, RouteTrackId).

String? IcueSdk.admissionNoFromPayload(Map)

Extract Admission Number

Safely extracts the student identification number from flat or nested notification data maps.

Future<void> IcueSdk.handleBackgroundMessage(RemoteMessage)

Background Isolate Handler

Processes background FCM payloads forwarded from top-level background isolates.

Data Models & Type Hierarchy

Type / Class Description & Key Properties
IcueNotifications Sealed push notification contract hierarchy:
• IcueNotifications.disabled()
• IcueNotifications.hostManaged({token, presentation, onNavigationIntent, ...})
• IcueNotifications.firebaseManaged({firebaseOptions, autoRequestPermission, presentation, ...})
IcueLaunchResult Sealed outcome returned by openLiveTracking:
• IcueLaunchSuccess() (isSuccess: true)
• IcueLaunchBuffered({identificationNo}) (isBuffered: true)
• IcueLaunchFailure({error}) (isFailure: true, errorMessage)
IcueSetupReport Diagnostic report returned by checkSetup() with isReady, issues, and toDiagnosticSummary() formatted output.
IcueNotification Pure-Dart notification model decoupled from Firebase: title, body, admissionNo, action, data, messageId, sentTime.
IcueNavigationIntent Typed navigation intent containing identificationNo, notification, action, and extras map.
IcueNotificationPresentation Foreground presentation modes: sdkBanner (in-app animated banner overlay), system (OS tray), hostManaged, none.
IcuePlatformCredentials Pure-Dart Firebase configuration model: apiKey, appId, messagingSenderId, projectId, iosBundleId.

Exception Hierarchy (IcueException)

Exception Thrown When Default Error Message
IcueNotInitializedException An SDK feature is accessed before IcueSdk.init(config) has been called and awaited. iCue SDK is not initialized. Await IcueSdk.init(config) before opening tracking or accessing features.
IcueInvalidStudentException An empty or whitespace-only student identification number is passed to openLiveTracking. Invalid or empty student identification number provided.
IcueNavigationException Navigation fails due to an unmounted BuildContext or missing root navigator state. Navigator state or BuildContext is not mounted. Ensure MaterialApp has navigatorKey: IcueSdk.navigatorKey.

Host-Owned Firebase Background Handlers

If your application owns the top-level Firebase background messaging handler, delegate iCue payloads to the SDK facade:

lib/main.dart 
@pragma('vm:entry-point')
Future<void> firebaseMessagingBackgroundHandler(RemoteMessage message) async {
  if (IcueSdk.isIcueNotification(message)) {
    await IcueSdk.handleBackgroundMessage(message);
  }
}

// When your host application receives a user tap on a notification:
if (IcueSdk.isIcuePayload(message.data)) {
  await IcueSdk.notifications.handleTap(message, context: context);
}

A comprehensive checklist for engineering, security, and QA teams prior to releasing an iCue-enabled app to app stores.

01

Environment Separation

Use distinct API credentials, Firebase projects, and Maps keys for development and production environments.

Restricted Client Keys

Troubleshooting

Common integration issues and how to resolve them quickly.

Symptom Root Cause & Resolution
"No Config" in logs Ensure IcueSdk.init is called and awaited before invoking any live tracking or notification methods.
Blank / gray map tiles Verify Google Maps SDK for Android / iOS is enabled in Google Cloud Console and billing is active on the linked cloud project.
No vehicle location shown The SDK queries bus telemetry from the iCue API (device GPS permissions are not required). Confirm the bus is actively running on a route in the iCue portal.
FCM token not registered Call IcueSdk.notifications.syncTokenWithBackend() or launch tracking for the student to synchronize device tokens with the backend.
Notification tap does not open tracking Confirm IcueSdk.navigatorKey is assigned to MaterialApp and IcueNavigatorObserver is registered in navigatorObservers.
iOS push notifications not arriving Confirm your APNs Authentication Key (.p8) is uploaded to Firebase Console and test on a real physical device (simulators do not support remote push).
